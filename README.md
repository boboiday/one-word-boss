# One Word for the Boss

One word describing a boss: **ReplyAll** — the boss who hits reply-all on everything and CCs the whole company.

Entry for the make.fun bounty [One Word for the Boss](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735).

## Run it

```sh
npx tsx main.ts
cat /output/entry.txt
```

Writes the single word `ReplyAll` (8 characters) to `/output/entry.txt`.
